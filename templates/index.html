    Host can register a local absolute path (file/folder) on the server machine. Receiver downloads directly with resume support.

    Browser security does not expose absolute host path from picker. Use Choose Folder for helper name, then paste host absolute path.

    Recommended for best speed: share a .zip file instead of a raw folder. Compress the folder to ZIP first for faster and more stable transfer.
